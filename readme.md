# Cupcake PCEX Activities

Python activities transformed from the English PCEX examples and challenges in the ADAPT Catalog v2:

https://adapt2.sis.pitt.edu/next.course-authoring/#/catalog-v2

## Contents

| Directory | Source catalog material |
|-----------|-------------------------|
| `catalogv2-en-workedexamples/` | English Python worked examples |
| `catalogv2-en-codecompletionproblems/` | English Python code-completion challenges |

Each activity lives in its own folder with:

- `main.py` — program source
- `<activity-id>.yaml` — Cupcake / Learning Contents activity definition

## Layout

```
catalogv2-en-workedexamples/
  <activity_id>/
    main.py
    <activity_id>.yaml

catalogv2-en-codecompletionproblems/
  <activity_id>/
    main.py
    <activity_id>.yaml
```
